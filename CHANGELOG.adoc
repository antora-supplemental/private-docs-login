* Detail: link:changelog-details/2026-11-19%20-%20login-provider.adoc[Login provider for private documentation].

=== Repository home is dev-centr

* The Git repository now lives at dev-centr/private-docs-login. The GitHub App name, the command name, and the environment prefix are unchanged.
* Detail: link:changelog-details/2026-11-19%20-%20repository-home.adoc[Repository home is dev-centr].

=== Membership broker

* The opening says this service brokers GitHub and GitLab membership for private documentation sites, before the login steps.
* Detail: link:changelog-details/2026-11-19%20-%20membership-broker.adoc[Membership broker].

* The post-install setup page and the page shown before a reader is sent to a forge state the shared issuer and the privacy limit, and link to the login contract. The GitHub App description is the short form GitHub shows on its own dialog.

=== Display name is Antora Private Docs Login

* The GitHub App and the GitLab application an owner approves are named Antora Private Docs Login.
* Detail: link:changelog-details/2026-11-13%20-%20login-display-name.adoc[Display name is Antora Private Docs Login].

* Antora Private Docs Login is one issuer. GitHub organizations install one app. GitLab groups opt in by inviting a configured user. The groups claim name and the listen address come from config.
