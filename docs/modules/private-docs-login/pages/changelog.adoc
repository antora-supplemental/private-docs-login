== 2026-11-19

=== Docs home and run command

* The how-to is the Dev-Centr docs page the playbook serves at https://docs.devcentr.org/tools/private-docs-login/how-to/ . This repository is the content source. The page is published on the next hub build.
* The README and the how-to run `antora-private-docs`, the package bin (`bin/antora-private-docs.mjs`).
* Sign-in and setup pages link to that how-to.
* Detail: xref:changelog-details/2026-11-19 - docs-home-and-command.adoc[Docs home and run command].

=== Support contact is DevCentr

* The README contact names DevCentr.org and support@devcentr.org. GitHub issues stay on dev-centr/private-docs-login. The how-to is on the Dev-Centr docs site.
* Detail: xref:changelog-details/2026-11-19 - support-contact.adoc[Support contact is DevCentr].

=== Login provider for private documentation

* The README, the how-to, the package description, and the GitHub App manifest description call this a login provider for private documentation sites that use OpenID Connect. Antora is one example. The GitHub App name, the command name, the npm name, and the environment prefix are unchanged.
* Detail: xref:changelog-details/2026-11-19 - login-provider.adoc[Login provider for private documentation].

=== Repository home is dev-centr

* The Git repository now lives at dev-centr/private-docs-login. The GitHub App name, the command name, and the environment prefix are unchanged.
* Detail: xref:changelog-details/2026-11-19 - repository-home.adoc[Repository home is dev-centr].

=== Membership broker

* The opening says this service brokers GitHub and GitLab membership for private documentation sites, before the login steps.
* Detail: xref:changelog-details/2026-11-19 - membership-broker.adoc[Membership broker].

=== Sign-in and setup screens

* The post-install setup page and the page shown before a reader is sent to a forge state the shared issuer and the privacy limit, and link to the login contract. The GitHub App description is the short form GitHub shows on its own dialog.
* Detail: xref:changelog-details/2026-11-19 - sign-in-and-setup-screens.adoc[Sign-in and setup screens].

=== How login works

* The README and the how-to put the login contract before setup: one published GitHub App, the issuer callback, relying-party clients, and when to host a separate issuer.
* Detail: xref:changelog-details/2026-11-19 - how-login-works.adoc[How login works].

== 2026-11-13

=== Display name is Antora Private Docs Login

* The GitHub App and the GitLab application an owner approves are named Antora Private Docs Login.
* Detail: xref:changelog-details/2026-11-13 - login-display-name.adoc[Display name is Antora Private Docs Login].

=== OpenID Connect issuer for GitHub and GitLab

* Antora Private Docs Login is one issuer. GitHub organizations install one app. GitLab groups opt in by inviting a configured user. The groups claim name and the listen address come from config.
* Detail: xref:changelog-details/2026-11-13 - private-docs-login.adoc[OpenID Connect issuer for GitHub and GitLab].
