A login provider for private documentation sites that use OpenID Connect.
GitHub and GitLab organization members sign in through their org's installation.
It brokers membership for those sites.
An Antora site behind Cloudflare Access, or another OpenID Connect relying party, is one common setup.

xref:how-to.adoc[How to host the issuer] is the published article: install the GitHub App, point a documentation site at the issuer, and host an issuer when policy requires it.

xref:environment-variables.adoc[Environment variables] names the settings.
Values stay out of git.
