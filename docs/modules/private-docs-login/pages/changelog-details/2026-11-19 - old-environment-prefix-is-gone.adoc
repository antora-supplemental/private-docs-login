== Old environment prefix is gone

The process reads environment names that start with `PRIVATE_DOCS_LOGIN_` only.
A value set under `ANTORA_PRIVATE_DOCS_` is ignored.
The app is new and has no deployments that depend on the previous prefix.

The documented names are unchanged.
`.env.example` and the environment variable page already list `PRIVATE_DOCS_LOGIN_` only.
